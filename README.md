# Лабораторна робота №4 — Файли

Дисципліна «Програмування мовою Java», ЧНУ імені Юрія Федьковича.
Виконав: Побережнюк Юрій Вікторович, група 241б.

**Варіант:** завдання 1 — №15, завдання 2 — №5

## Завдання

| № | Головний клас | Що робить |
|---|---|---|
| 1 | `task1.Main` | Вилучення повторів рядків, сортування за абеткою, запис у файл (вхід: `data/cities.txt`) |
| 2 | `task2.Main` | Посимвольний запис з консолі у файл (кінець введення — Ctrl+Z, потім Enter) |

Вхідні файли лежать у папці `data`; конфігурації запуску в IDEA вже запускають програми з неї, тож ім'я файлу можна вводити без шляху (наприклад, `cities.txt`).

## Як запустити

**IntelliJ IDEA:** File → Open → папка `Laba_4_Java`. Якщо IDEA попросить JDK, натисни *Setup SDK* → *Download JDK* (підійде будь-яка версія від 8).
Для кожного завдання вже є конфігурація запуску — обери її у списку вгорі праворуч і натисни ▶.

**Командний рядок** (з кореня проєкту):

```
javac -encoding UTF-8 -d out src/common/*.java src/task1/*.java src/task2/*.java
cd data
java -cp ../out task1.Main
```

Код сумісний з Java 8 і новішими.
